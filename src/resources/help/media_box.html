Media Library

Now let's look a little closer at the Media Library.

Here is where you can create and choose different media items for your services. Items include:

  • Songs: The lyrics for hymns and praise songs
  • Bible: Scripture passages to be shown during the service
  • Custom Slides: Slides with your own text
  • Images: Any images you may want to show during the service
  • Videos: Any videos you may want to show during the service
  • Web Slides: Internet content you may want to show during the service

Buttons

Each of these tabs has a set of buttons you can use to perform various tasks:

  • Create a new item
  • Create a new folder
  • Add to Order of service
  • Send to Live

Additionally, if the tab has a search box, use to clear the search box.

Clicking the Create a new item icon will allow you to create a new media item in the tab you currently have selected.

Clicking the Create a new folder icon will prompt you to enter a name for your new folder. You can use this folder to organize your songs, custom slides, images, etc. Simply drag-and-drop your media items into the folder, or right-click on your item(s) and select "move to folder" to choose the folder to move to.

Clicking the Add this item to the Order of service button will add your currently-selected item to the Order of Service list. You can also add media items to the order of service by drag-and-dropping them or by right-clicking them and selecting "Add to Order of Service".

Clicking the Send to Live button will send your selected item directly to the display without adding it to the order of service. This is useful when a slide is found to be missing as the service is currently happening.

Context Menu

Right-clicking on an item in the Media Library will bring up a menu where you can move that item to an existing folder, add that item to the order of service, remove the item from the program or, in the case of songs and custom slides, edit the item.

A note about scripture passages...

The best way to use the Bible tab of the Media Library is to import your favorite bible version(s) and add them to the service through the "Enter Passage" box. However, if you would prefer not to import a bible, or if you would like to show a passage from a version you rarely use, simply paste the text of that passage into the lower box of this tab. Ensure that your pasted text includes verse numbers or this will not work as expected.
